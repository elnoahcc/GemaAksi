<h1>🌐 GEMA AKSI Website</h1>

<p>🚀 <strong>GEMA AKSI</strong> adalah website interaktif yang dikembangkan untuk lomba 
<strong>Bytefest UNS 2025</strong> dan berhasil meraih <strong>Juara 1</strong>.<br>
Website ini dirancang untuk memberikan pengalaman digital yang modern, informatif, 
dan engaging, dengan tampilan responsif serta performa optimal.</p>

<hr>

<h2>🏆 Prestasi</h2>
<ul>
  <li>🥇 <strong>Juara 1 Bytefest UNS 2025</strong></li>
  <li>Kategori: Web Design</li>
</ul>

<hr>

<h2>📖 Cara Menjalankan Project</h2>
<ol>
  <li>Install Dependencies
    <pre><code>npm install</code></pre>
  </li>
  <li>Jalankan Development Server
    <pre><code>npm run dev</code></pre>
  </li>
  <li>Buka Website  
    <br>👉 <a href="http://localhost:3000">http://localhost:3000</a>
  </li>
</ol>

<hr>

<h2>🛠️ Teknologi yang Digunakan</h2>
<ul>
  <li><a href="https://nextjs.org/">Next.js</a> – React Framework untuk aplikasi web modern</li>
  <li><a href="https://reactjs.org/">React</a> – Library UI berbasis komponen</li>
  <li><a href="https://tailwindcss.com/">Tailwind CSS</a> – Utility-first CSS framework</li>
  <li>CSS Custom – Penyesuaian tambahan agar tampilan lebih unik</li>
</ul>
